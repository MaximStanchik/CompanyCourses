# Исправление базы данных

## Проблема
Поле `targeting` в таблице `Course` не существует в базе данных, хотя оно определено в схеме Prisma.

## Решение

### Вариант 1: Применить существующую миграцию (рекомендуется)

1. Перейдите в папку `backend`:
   ```bash
   cd backend
   ```

2. Примените миграцию:
   ```bash
   npx prisma migrate deploy
   ```

3. Перезапустите сервер:
   ```bash
   node index.js
   ```

### Вариант 2: Создать новую миграцию

Если первый вариант не работает:

1. Перейдите в папку `backend`:
   ```bash
   cd backend
   ```

2. Создайте новую миграцию:
   ```bash
   npx prisma migrate dev --name fix-targeting-field
   ```

3. Перезапустите сервер:
   ```bash
   node index.js
   ```

### Вариант 3: Проверить статус миграций

1. Проверьте статус миграций:
   ```bash
   npx prisma migrate status
   ```

2. Если есть проблемы, сбросьте базу данных и примените миграции заново:
   ```bash
   npx prisma migrate reset
   npx prisma migrate dev
   ```

## Проверка

После применения миграции поле `targeting` должно появиться в таблице `Course` и все функции редактирования курса должны работать корректно.
