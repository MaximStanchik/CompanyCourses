# Система загрузки файлов с прогрессом и отменой

## Обзор

Новая система загрузки файлов работает по принципу **"отправить сообщение сразу, загрузить файл в фоне"**. Это обеспечивает лучший пользовательский опыт и позволяет пользователям видеть сообщения мгновенно.

## Как это работает

### 1. Отправка сообщения
- Пользователь выбирает файл
- Вводит подпись (опционально)
- Нажимает "Отправить сообщение"
- **Сообщение отправляется в чат сразу** с информацией о файле
- Файл начинает загружаться в MinIO в фоне

### 2. Отображение в чате
- Сообщение появляется у всех пользователей мгновенно
- Показывается статус "Файл загружается..." с анимированным индикатором
- После завершения загрузки файл становится доступным для скачивания

### 3. Загрузка в MinIO
- Файл загружается по частям (чанкам) для отслеживания прогресса
- Поддерживается пауза/возобновление загрузки
- Возможна отмена загрузки
- Отображается скорость загрузки и оставшееся время

## Компоненты

### FileUploadProgress
Компонент для отображения прогресса загрузки файла с возможностями:
- Показ статуса загрузки
- Прогресс-бар с анимацией
- Статистика (скорость, оставшееся время)
- Кнопки управления (пауза, отмена)
- Поле для подписи к файлу

### Backend Endpoints
- `/api/files/upload-with-progress` - загрузка с прогрессом
- `/api/files/upload-status/:uploadId` - статус загрузки
- `/api/files/upload/:uploadId` - отмена загрузки

## Статусы загрузки

- **`preparing`** - файл готов к отправке
- **`uploading`** - файл загружается
- **`paused`** - загрузка приостановлена
- **`completed`** - загрузка завершена
- **`error`** - ошибка загрузки
- **`cancelled`** - загрузка отменена

## Преимущества новой системы

1. **Мгновенная отправка сообщений** - пользователи видят сообщения сразу
2. **Лучший UX** - нет необходимости ждать завершения загрузки
3. **Отслеживание прогресса** - видно, как идет загрузка
4. **Возможность отмены** - можно прервать загрузку
5. **Пауза/возобновление** - контроль над процессом загрузки
6. **Статистика** - скорость и время загрузки

## Использование

### Для пользователей
1. Выберите файл для отправки
2. Добавьте подпись (необязательно)
3. Нажмите "Отправить сообщение"
4. Сообщение появится в чате сразу
5. Файл загрузится в фоне

### Для разработчиков
Система автоматически:
- Создает временные ID для файлов
- Отправляет обновления через WebSocket
- Обновляет UI при изменении статуса
- Обрабатывает ошибки загрузки

## Технические детали

- Используется `AbortController` для отмены загрузки
- Файлы разбиваются на чанки по 1MB для отслеживания прогресса
- WebSocket события: `file-upload-complete`, `file-upload-error`
- Автоматическая очистка временных записей (старше 1 часа)
